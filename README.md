# Gaurav Agarwal Tower

My portfolio as an 828 m tower. Start outside with every floor labelled, walk in through the entrance, then ride the lift one floor at a time. Each floor is a furnished room for one chapter of my work, and the boards on its walls open the details of what I did there.
